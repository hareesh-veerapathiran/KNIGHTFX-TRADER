# KNIGHTFX TRADERS

A Next.js, TypeScript and Tailwind site built around the supplied KNIGHTFX logo.

## Start locally

1. Install dependencies with `npm install`.
2. Run `npm run dev` and open http://localhost:3000.
3. Create a production build with `npm run build`.

## Update brand details

Edit the files in `data/` to add confirmed mentorship and workshop registration URLs, official partner URLs and logos, social profiles, legal page URLs, and the public site URL. Keep `isPartner` false until each relationship is confirmed. Add only verified discounts. The workshop defaults to waitlist mode and its capacity is configured in `data/programs.ts`.

The supplied image is used at `public/assets/knightfx-logo.jpg` without alteration. Replace it with an official source asset only when provided.
